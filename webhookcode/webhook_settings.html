Setup Instructions
Stripe Setup
  1. Go to the Stripe Dashboard Webhooks section.
  2. Click "Add endpoint" and enter your webhook URL: {{ webhook_base_url }}/api/v1/webhooks/stripe
  3. Select these events to receive:
    • checkout.session.completed
    • invoice.payment_succeeded
    • customer.subscription.created
    • customer.subscription.updated
    • customer.subscription.deleted
  4. Copy the signing secret and paste it in the Webhook Secret field above.
  5. Make sure to save your settings!
