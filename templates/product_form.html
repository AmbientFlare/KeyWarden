Product Features Guide

The features field allows you to define capabilities that can be included in licenses for this product. These are stored as a JSON object and can be used to control access to different functionality in your application.

Example Features:
{
  "max_users": 10,
  "premium_support": true,
  "export_formats": ["pdf", "excel", "csv"],
  "modules": {
    "analytics": true,
    "reporting": true,
    "automation": false
  }
}

Your client application can check these values to enable or disable functionality based on the license.
