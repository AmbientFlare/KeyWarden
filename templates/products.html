Product Management Guide

Products represent the software applications that you want to license. Each product can have multiple license keys associated with it.

Key Product Features:
  • Name and Version: Identify your products clearly
  • Feature Flags: Define features that can be enabled or disabled per license
  • License Management: Create and track licenses for each product
  • Usage Analytics: Monitor how your products are being used
Best Practices:
  • Create separate products for major versions that require different licensing
  • Use feature flags to implement tiered licensing (e.g., "basic", "pro", "enterprise")
  • Define any usage limits in the product's feature configuration
