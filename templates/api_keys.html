About API Keys

API keys are used to authenticate requests to the license server API. They are required for all API requests, including license validation and activation.

Important: API keys are shown only once when they are created. Make sure to save them in a secure location.
API Key Types:
  • Client Keys (usr-...): Use these for your software clients. They can only access license validation, activation, deactivation, and heartbeat endpoints.
  • Admin Keys (adm-...): These have full access to all API endpoints, including license creation, client management, and reports. Use with caution and only in secure environments.
API Usage Examples:
Validate a License (Client Key):
curl -X POST http://your-server:1776/api/v1/validate \
  -H "X-API-Key: usr-your-client-api-key" \
  -H "Content-Type: application/json" \
  -d '{"license_key": "XXXX-XXXX-XXXX-XXXX"}'
Activate a License (Client Key):
curl -X POST http://your-server:1776/api/v1/activate \
  -H "X-API-Key: usr-your-client-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "license_key": "XXXX-XXXX-XXXX-XXXX",
    "ip_address": "192.168.1.1",
    "hardware_id": "optional-hardware-id",
    "system_info": {
        "platform": "Windows",
        "version": "10.0.19044"
    }
  }'
Check License Status (Client Key):
curl -X POST http://your-server:1776/api/v1/heartbeat \
  -H "X-API-Key: usr-your-client-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "activation_id": 12345,
    "hardware_id": "optional-hardware-id"
  }'
Admin API Example (Admin Key Only):
curl -X GET http://your-server:1776/api/v1/admin/licenses \
  -H "X-API-Key: adm-your-admin-api-key" \
  -H "Content-Type: application/json"
